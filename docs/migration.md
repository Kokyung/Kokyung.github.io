대표 작업은 Unity 6 XR(렌더링·AI 워크플로우·실기 검증), 프로젝트 버추얼(단독 시스템 설계·개발), Magem(독립 앱 제작·릴리즈)입니다. 세 가지 서로 다른 구현 역량을 먼저 탐색하도록 배치했습니다. 원문 전체는 상세 페이지에 남아 있습니다.

## 명시적인 제한 및 보완

Notion 커넥터가 `unknown`으로 반환한 블록은 13개입니다. 2개는 외부 객체 미리보기, 10개는 다음 페이지 alias, 1개는 copy_indicator입니다. 이런 반환이 있는 문서는 `truncated` 표시를 보존했습니다. 이 표시는 이 사례에서 본문 텍스트 길이 제한 대신 미지원 블록과 함께 나타났습니다.

GitHub 미리보기는 공개 Notion UI에서도 로딩 상태로 남아 목적지 URL을 읽을 수 없었습니다. 동일 작성자·프로젝트의 공개 저장소를 별도로 확인하여 실제 저장소 링크로 보완했습니다. 원본 스냅샷 자체는 변경하지 않았습니다.

- Magem: https://github.com/Kokyung/Magem
- Unity 생성기: https://github.com/Kokyung/UnityChatGPTScriptGenerator

10개 alias와 copy_indicator는 원문 블록 링크로 보존했습니다. 대상 페이지 본문은 사이트 내부에 이미 이관되어 있으며, 상위 경로·하위 링크·관련 문서·전체 아카이브를 통해 이동할 수 있습니다. 미지원 블록의 내부 메타데이터를 완전히 재현했다고 주장하지 않습니다.

FPS 방명록에 포함된 apption.co, joey.team은 외부 서비스이므로 원래 주소로 연결합니다. 댓글 데이터 및 외부 서비스의 작동 여부를 복제하거나 보장하지 않습니다. YouTube의 재생 가능 여부는 원본 영상 공개 상태와 임베드 정책에 따릅니다.
